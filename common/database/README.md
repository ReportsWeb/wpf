# サンプルで使うデータ

`sample.db` は、請求書・見積書・郵便番号一覧・商品一覧などのデータを収めたSQLiteファイルです。データベースサーバーのインストールや接続先の登録は不要です。

02、03、04のサーバー側プログラムが、このファイルをSQLで読み取ります。01は短いコードで基本を試すため、データベースを使いません。04のクライアント側にもデータベースは不要です。

全言語で同じ帳票定義と同じサンプルデータを使用する方針で、ここにはWASM版のPostgreSQLと同じ内容をSQLite形式で収録しています。データを取得するために、当社のサーバーやAzureへ接続することはありません。

## データを変えて試すには

SQLiteに対応したツールで `sample.db` を開くと、テーブルとデータを確認できます。変更する前にこのファイルをコピーして控えを残してください。同じファイルを読む02・03・04のサーバー側すべてに変更が反映されます。変更後は帳票をもう一度作成してください。

主なテーブルは `郵便番号テーブル`（2,592件）、`見積ヘッダ`／`見積明細`、`請求ヘッダ`／`請求明細`、`M_商品`（27件）です。

WPF/.NETのサンプルはWindows上で直接起動します。Dockerの準備は不要です。
