.NET

サーバーの.NETで、帳票をつくる。

Reports Web / ASP.NET Core Webデモ
WebAssemblyを使わず、サーバー上の.NETエンジンで作成した帳票を、ブラウザーのプレビュアーで表示します。

プレビュアー

ツールバーを表示すると、PDF表示・印刷・検索などを試せます。非表示にすると、帳票だけをアプリに組み込む使い方を体験できます。

.NETの業務アプリへ、完成した帳票エンジンを。

ASP.NET Coreの業務アプリ → .NETエンジン → ブラウザーでプレビュー・必要に応じてPDF出力

.NETライブラリを直接呼び出して帳票を生成します。Windowsの業務資産を生かす構成にも、ASP.NET CoreのWebアプリにも組み込めます。
