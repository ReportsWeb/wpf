# 01. あっという間に帳票出力

## このサンプルで分かること
このサンプルは完成画面を見るためのデモではありません。C#の短いソースと帳票定義を開き、自分で値やレイアウトを変更して、プレビュー、PREPEJ、ページ単位SVG、PDFへ反映される流れを学ぶ最初の開発サンプルです。

## デザインも変えてみましょう

起動後、画面上部の「デザイナーでデザインを変更」を押します。文字・色・配置を変えてデザイナーで上書き保存し、サンプルへ戻るとプレビューが更新されます。プレビュアーのPDF保存も更新後の内容を使います。デザイナーを閉じる必要はありません。保存後にサンプル画面をクリックすると、ファイルの変更を確認して自動反映します。未保存の変更は反映しません。

編集用ファイルは、このサンプルの `output/design-session/quick-report.prepdj` です。元の帳票定義は上書きしません。編集結果は次回も残り、元に戻したいときは画面を閉じてこの編集用ファイルだけを削除します。ソースの値を差し替える練習とは別に、現在の文字を直接デザインで編集できます。

デザインの変更には、製品の[体験版 ZIP](https://www.pao.ac/reports.web/index.html#download)に同梱の WPF デザイナー（`Tools/Designer-net10`）を使います。

## 必要な環境

以下は.NET 10版の手順です。.NET Framework 4.7.2以降のアプリへ組み込む方は、[互換版の入口](Compat-net472/README.md) を開いてください。同じ帳票作成コードを使う専用プロジェクトがあります。

- Windows
- .NET 10 SDK

このプロジェクトは NuGet パッケージ [`Reports.Web.Wpf`](https://www.nuget.org/packages/Reports.Web.Wpf) を参照するため、ビルド時に自動で取得されます。依存先を手で書き換える必要はありません。

## 起動
`start.cmd`をダブルクリックするか、このフォルダーで次を実行します。
```powershell
.\start.ps1
```

## 生成物の確認
通常起動では印刷プレビューが開きます。タイトル「あっという間に帳票出力」、会社名、金額を確認し、ツールバーからPDF保存や印刷を試せます。

画面を開かず確認する場合は`.\start.ps1 --verify .\output`を実行します。

- `output/quick-start.prepej`: 定義と値を保持した1ページの印刷データ
- `output/quick-start-page-1.svg`: 1ページ目のSVG
- `output/quick-start.pdf`: 全1ページのPDF

## 開発環境でサンプルを開く

Visual Studio 2026では、［プロジェクトまたはソリューションを開く］で、このフォルダーの`Pao.Reports.Wpf.QuickStart.csproj`を選び、F5で実行できます。「.NETデスクトップ開発」のワークロードが必要です。まず`QuickStartReport.cs`を開くと、帳票を作る短いコードが読めます。

Visual Studio Code や Cursorでは、このREADMEがあるフォルダーを開いてください。統合ターミナルから次のコマンドでも起動できます。ほかの.NET対応エディターやIDEも利用できます。

```powershell
dotnet run --project Pao.Reports.Wpf.QuickStart.csproj
```

スクリプトはこの起動操作をまとめた補助です。ソースの編集・ビルド・実行にスクリプトが必須なわけではありません。

## 最初に読むソース
`QuickStartReport.cs`です。定義読込、値設定、ページ確定だけを画面制御から分けています。

`QuickStartReport.cs`にある変更前のタイトル`「あっという間に帳票出力」`を、例として`「初めてのC#帳票」`へ書き換えます。会社名も変更でき、いったんプレビューを閉じて再実行すると反映されます。C#は再実行時に再コンパイルされます。レイアウトは`quick-start.prepdj`をデザイナーで変更し、保存後に再実行します。

## 帳票定義と入力データ
`quick-start.prepdj`が帳票定義です。4つの入力値は`QuickStartReport.cs`に並べています。装飾文字は使用していません。

## 停止
プレビューを閉じれば終了します。常駐プロセスやサーバーはありません。
